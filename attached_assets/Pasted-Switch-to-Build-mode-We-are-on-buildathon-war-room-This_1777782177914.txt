Fix requirements:

- user must be able to type a full repo string continuously

- Scan Public Repo button must enable after input is non-empty
- no re-render/remount should steal focus after each keystroke

Inspect artifacts/repoguard/src/components/WarRoom.tsx.

Likely causes to check and fix:

- SectionLabel / Tile / inline component definitions causing remounts

Required implementation:
